# LeWeChatCopy WordPress 关注公众号可复制插件

一款WordPress关注公众号可复制插件，支持全站或指定内容的复制控制。

## 功能特点

- 支持全站内容复制控制
- 支持使用短代码指定内容复制控制
- 自定义验证码设置
- 自定义公众号二维码图片
- 自定义弹窗提示文字
- 响应式设计，支持移动端
- 支持按Enter键验证

## 安装方法

1. 下载插件压缩包
2. 在WordPress后台点击"插件" -> "安装插件"
3. 点击"上传插件"按钮，选择下载的压缩包
4. 安装完成后点击"启用"

## 使用方法

### 基本设置

1. 在WordPress后台点击"设置" -> "公众号关注复制"
2. 勾选"启用插件"
3. 选择复制控制类型：
   - 全站复制控制：所有内容都需要验证后才能复制
   - 短代码控制：仅限制使用短代码包裹的内容
4. 设置验证码
5. 上传或选择公众号二维码图片
6. 设置弹窗提示文字
7. 点击"保存更改"

### 短代码使用

如果选择"短代码控制"，可以使用以下短代码来包裹需要控制复制的内容：

```
[lewechatcopy]需要控制复制的内容[/lewechatcopy]
```

## 注意事项

1. 请确保上传的二维码图片清晰可扫
2. 建议设置简单易记的验证码
3. 弹窗提示文字建议简明扼要
4. 如使用短代码控制，确保短代码前后无多余空格

## 常见问题

Q: 为什么启用插件后复制功能没有限制？
A: 请检查是否已勾选"启用插件"选项，并确保已保存设置。

Q: 为什么短代码不生效？
A: 请确保：
1. 已选择"短代码控制"模式
2. 短代码格式正确，无多余空格
3. 已保存设置
